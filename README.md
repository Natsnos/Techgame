# Skillforge

A browser game for learning Python, AI, cybersecurity, and networking and servers.
Walk around a night-time town, enter a shop, and work through levels from beginner to advanced.

It is one static file (`index.html`) with no build step.

## Run it
Open `index.html` in a browser, or host it with GitHub Pages (below).

## Host it on GitHub Pages
1. Create a new repository on GitHub and upload `index.html` and `README.md`.
2. Go to Settings, then Pages.
3. Under "Build and deployment", set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute your game is at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
5. Add `#selftest` to that address to check that fonts, sound and the Python runner load on your connection.

Progress and your character are saved in each visitor's own browser.
